# Portfolio cybersécurité - Hackus Mans

Ce dépôt contient un portfolio cybersécurité statique avec une interface d'administration Git-based.

## Objectif

- Site public professionnel pour présenter le profil, les compétences, les projets, les articles et les certifications.
- Interface `/admin/` pour modifier le contenu sans toucher au code.
- Aucune base de données.
- Hébergement gratuit possible avec GitHub Pages.

## Publication gratuite recommandée

Pour obtenir l'adresse gratuite `https://hackus-mans.github.io`, le dépôt doit idéalement s'appeler :

```text
hackus-mans.github.io
```

Ensuite, dans GitHub :

```text
Settings > Pages > Deploy from a branch > main > /root
```

## Modification sans coder

Après publication, aller sur :

```text
https://hackus-mans.github.io/admin/
```

L'interface admin permet de modifier :

- Le profil
- Les compétences
- Les projets
- Les articles
- Les certifications
- Les liens de contact

## Sécurité

Ne jamais publier de mots de passe, clés API, données privées, vraies cibles ou captures contenant des informations sensibles.

Les contenus cyber doivent rester pédagogiques, réalisés dans un laboratoire autorisé.
